# Retired Convex guides (archived 2026-11-24)

These four guides date from the first Convex setup. They are kept for history
only. They show hand-run `npx convex dev` and `npx convex deploy --prod`
commands, which `AGENTS.md` forbids, and call functions such as
`api.persons.get` that pages can no longer reach.

For current practice read [How production deploys](../../operations/how-production-deploys.md)
and [`convex/README.md`](../../../convex/README.md).
