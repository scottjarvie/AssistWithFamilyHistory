# Retired FamilySearch console extractor (archived 2026-11-24)

These two guides describe pasting `fs-extractor.js` and `fs-sources-extractor.js`
into the browser console and importing with `fs-to-convex.ts`. Those scripts now
live in `scripts/legacy/`, and its README says none of them run as-is: they call
Convex functions that are internal-only.

The current capture route is the Chrome extension in `extension/`; see the
[FamilySearch source capture runbook](../../importing/familysearch-source-capture-runbook.md).
