- Opening a person loads the whole dossier, even when you only want the Overview.
- Queue waits for the browser to start before it asks for your handoffs.
- A place summary waits for six tabs that may never be opened.
- Queue badges repeat count requests, and rare searches can read your whole list.
- Some backend paths can continue after a failed owner check or use AI permissions that have just changed.
