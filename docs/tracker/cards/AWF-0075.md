## Why this exists

Operation Cleanup, Stage 3. The `/app/library` shell page shipped with #88 but
does not match the canonical Site Guide. Drafted on oldwin against `feb4f5f`;
re-checked here against `main` at `d2b0552`.

## Current truth

- **Wrong shelves.** The page shows Research · Prompts · Resources
  (`app/app/library/page.tsx:70`, sections at 79, 104, 122). The Site Guide
  says Research · Sources · Instructions, plus a Stories shelf
  (`docs/planning/site-guide.md:118` and `:226`).
- **Sources and Stories are never loaded.** `readLibraryShelves` reads only
  `researchLog`, `researchTasks`, `historicalContext` and `topics`
  (`convex/yourData.ts:101-107`).
- **Research rows are not links.** Each finding or task renders as a plain
  `<span>` title with no route to the record (`app/app/library/page.tsx:92`).
  - Restart: give each finding and task one stable destination, and test that
    every link opens its record.
- **No way to choose a Source for the shelf.** The Site Guide says the Sources
  shelf is a flag on the sources the person returns to most (the family Bible,
  a journal), not every source. The `sources` table has no such field
  (`convex/schema.ts`, `sources: defineTable`).

## Next safe action

Build the four canonical shelves from existing records: add an optional,
owner-set source-selection flag (for example `onLibraryShelf`) with an
indexed bounded read; load Stories from `stories`; turn Prompts into the
Instructions shelf; give every listed record a working link. Add the new field
to export parity (`lib/vault/exportTables.ts` already exports `sources`).

- `app/app/library/page.tsx` (147 lines) and `convex/yourData.ts:101-150` on `d2b0552`.
- `docs/planning/site-guide.md:96`, `:118`, `:226`, `:255`.
