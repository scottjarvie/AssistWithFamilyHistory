## Why this exists

Private family-history software should reduce browser attack surface and prove
that only intended public client configuration ships to visitors.

## Current truth

Production sends HSTS, `X-Frame-Options: DENY`, nosniff, restrictive camera/
microphone/geolocation policy, and strict-origin referrer policy. A fresh header
check and public crawl found no Content-Security-Policy. The crawl flagged a
Stripe publishable key in a client dependency; publishable keys are designed to
be public, so this is an unverified scanner signal rather than a secret leak.
No private key was observed.

## Scope

- Design and deploy a CSP compatible with Next.js, Clerk, Convex, approved AI/
  media origins, and required development/preview differences.
- Inventory public runtime variables and client bundles; classify every key as
  intentionally public, masked, or prohibited.
- Verify CORS, framing, referrer, permissions, HSTS, MIME, source-map, error,
  and mixed-content behavior on public and authenticated routes.
- Add report-only rollout/telemetry before enforcement where appropriate.

## Next safe action

Create a header/source inventory and CSP report-only policy in a protected
preview branch; do not rotate or change provider keys from this Card without a gate.

## Unknowns and access limits

Authenticated response headers, third-party origin needs, CSP violations,
source-map publication, and provider dashboard settings are unverified.

## Evidence

Acceptance evidence includes header snapshots, CSP report-only/enforced tests,
client-bundle key classification, mixed-content/CORS/framing checks, Clerk and
Convex journeys, and no regression in public/app routes.

## Definition of done

- [ ] Enforced production CSP permits only required origins and behaviors.
- [ ] Public client configuration is inventoried and contains no prohibited secret.
- [ ] Auth, Convex, media, AI, and story routes work under the policy.
- [ ] Security headers are tested on public, auth, app, API, and error responses.
- [ ] Scanner warnings are resolved or documented with evidence, not assumption.
- [ ] PR/CI/deployment, live header proof, and independent audit exist.
