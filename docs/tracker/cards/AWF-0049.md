## Why this exists

This was the first Codex run for the project on this computer. The documented
single full-check command could not run because the host's WSL/Bash integration
is broken. Running the same steps individually exposed four additional
Windows-only contract failures, which makes an otherwise healthy branch look
unverifiable and risks hiding a real regression among platform noise.

## Current truth

- The repository pins Node 20, while this shell currently runs Node 24.16.0.
- The active branch now normalizes platform line endings for generated-content
  comparisons and tracker parsing without weakening substantive equality.
- The support-contact check now normalizes Windows paths before applying its
  forward-slash allowlist.
- The extension runtime check invokes the checked-in TypeScript compiler
  directly, avoiding `spawnSync pnpm.cmd EINVAL` under Node 24.
- `pnpm verify` now selects Git Bash explicitly on Windows instead of the broken
  WSL shim on this computer.
- Fifty-two of the prior fifty-seven individual verification steps, including
  the production build, passed before the media branch began. Current reruns
  pass tracker parity but reproduce the other four host-specific failures. They
  are portability gaps, not a claim that the media branch is released.

## Next safe action

Push the verified branch and require GitHub CI to run the same strict checks.
If CI passes, record the retained run URL and close this outcome; if CI exposes
a Linux-only regression, fix it without reverting the Windows guarantees.

## Constraints

- Do not normalize or rewrite unrelated tracked files just to silence parity.
- Keep Linux/CI behavior and exact generated-artifact detection intact.
- Do not weaken content equality, skip the extension, or make a failed command
  look successful.
- This is software work and requires its own Ready/Active Work Order or an
  explicitly approved addition to one, then normal PR/CI/deployment handling.

## Definition of done

- [x] Generated-content checks normalize platform line endings while retaining
      substantive equality.
- [x] Generated bindings, tracker, Philosophy, and support-path checks pass on
      Windows and Linux from clean checkouts.
- [x] The extension check runs under the pinned Node runtime in CI and under
      Node 24 on this Windows checkout.
- [x] One documented full command completes all steps on this computer.
- [x] CI remains green and no unrelated file received a mechanical rewrite.
