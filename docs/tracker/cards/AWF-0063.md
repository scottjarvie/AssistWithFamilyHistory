## Why this exists

The connection works but misses several small family-standard requirements that
real clients trip on.

## Current truth (audit 2026-10-06)

- `www.` machine paths (`/mcp`, both protected-resource metadata paths,
  `/ai.txt`, `/llms.txt`) answer 307 to the apex instead of directly.
- `scopes_supported` omitted, so `offline_access` is never advertised; token
  renewal untested.
- JWKS/verifier outages return 401 instead of 503 (`convex/httpRoutes/mcp.ts`).
- `capabilities.tools` not declared when the tool list is empty.
- No-token challenge includes `error="invalid_token"`.
- `/llms.txt` is hand-written, names alias tools and is out of date; initialize
  instructions do not point at `/ai.txt`.
- `/ai` has no per-client steps or "did it work?" check.
- Output schemas and `openWorldHint` (AWF-WO-014 sequence).

## Next safe action

Fix the server-side items behind tests, then the Vercel domain setting for www.
