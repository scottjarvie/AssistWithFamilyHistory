## Current truth

The Settings page saves `autoRedact` and `adminMode` in the browser's
`telltheirstories-settings` object. Source processing instead uses its own
`useRedacted` state and explicit review acknowledgement. Story Writer separately
blocks living-person context and media needing privacy review. Neither processing
route reads the saved `autoRedact` flag in current repository source.

The extension reads `adminMode` from `chrome.storage.local`, while the site writes
its similarly named flag to page `localStorage`. No synchronization bridge was
found among the current repository references; that is source-search evidence,
not proof about an independently installed extension or external integration.

The design pass retains both flags, their defaults, storage key, toggles and Admin
Mode confirmation. It makes their wording describe these actual boundaries.
It does not connect the flags to processing, weaken redaction/living-person gates,
alter extraction pacing, or change production access. No real key, private vault
record or provider request was inspected.

## Next safe action

Use offline fixtures to establish intended preference behavior and extension
synchronization. Decide whether these are legacy compatibility fields or active
preferences. Propose a bounded integration or retirement with compatibility and
privacy expectations; never let a saved false flag bypass explicit review.
