## Why this exists

The AI can only help with what its tools reach. Today it cannot browse by
surname or place, open several records at once, touch places, context, the
research log or possible matches, add a Queue item, park a suggestion, or use a
Library.

## Current truth

16 tools; search requires text, has only `kinds`, no cursor; one record per read;
no place, topic, question, list, Library, Queue-add or Suggestions tools.

## Scope

- Find tools with the page filter families and cursors; batch read.
- Save and read for every Site Guide block (Projects, Questions with plan and log, Claims
  with states, Possible matches, Topics, Notes dictated by the person, Lists).
- Queue add (for the person and the AI's own follow-ups) and AI Suggestions.
- Library catalogue and check-out; connection self-inspection and opt-out.
- Workspace overview includes Preferences and Library catalogue.
- Keep tools few and domain-shaped; one catalogue; no generic CRUD.

## Next safe action

Design the target catalogue against the Site Guide blocks before adding tools.
