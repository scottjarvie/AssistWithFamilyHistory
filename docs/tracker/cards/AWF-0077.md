## Current truth

### FH-R007 · A missing capture receipt attaches a document to the wrong import

- **What happens:** when the capture id has no import-run receipt, the raw or
  contextualized document is attached to whatever import of that person is
  newest, not the one it came from.
- **Cause:** `lib/familysearch/importRunResolver.ts:44-54` falls back to
  `listRecent(limit: 1)`; callers in `app/api/people/[id]/raw/route.ts` and
  `contextualized/route.ts` then patch paths via `convex/importRuns.ts:155-187`.
- **Smallest fix:** return no import run when a capture id is given but not found.
- **Why it matters:** provenance points at the wrong capture.

### FH-R009 · An uploaded original-only file returns 404 to its owner

- **What happens:** a B2 upload with no medium rendition (or not yet `ready`)
  cannot be opened at `/api/media/[mediaId]/file`.
- **Cause:** `convex/vault.ts:1566` serves B2 only for `ready` + `medium`;
  `:1574` returns null without a legacy `storageId`;
  `app/api/media/[mediaId]/file/route.ts:34-35` turns that into 404.
- **Smallest fix:** fall back to the signed `b2Original` for the owner.
- **Why it matters:** the owner cannot see their own original.

### FH-R010 · "AI use needs usable rights" is checked only in the web route

- **What happens:** any other caller of `reviewMedia` can set
  `aiUseAllowed: true` on unreviewed or restricted media.
- **Cause:** the rule is in `app/api/media/review/route.ts:44-49`; the mutation
  `convex/vaultMutations.ts:1281-1330` writes `aiUseAllowed` unchecked (`:1321`).
- **Smallest fix:** move the same check into the mutation and throw.
- **Why it matters:** the privacy gate should live where the data is written.

### FH-R011 · Re-importing the same capture raises the supporting-record count

- **What happens:** each re-import of one capture adds 1 to a provisional
  relative's evidence count.
- **Cause:** `convex/vaultMutations.ts:2099` always does
  `evidenceCount: existing.evidenceCount + 1`, even when `sourceKey` is already
  in `sourceKeys` (`:2097`).
- **Smallest fix:** set the count to the size of the de-duplicated `sourceKeys`.
- **Why it matters:** inflates how well-supported a possible relative looks.
