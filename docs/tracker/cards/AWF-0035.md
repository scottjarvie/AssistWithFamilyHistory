## Why this exists

The durable product name and normal public address are **Assist With Family
History** and `assistwithfamilyhistory.com`, but current public, signed-in,
extension, metadata, documentation, and provider surfaces still mix in the
retired Discover Their Stories identity. The emergency sign-in repair restored
the Clerk form by sending the new domain back to the old one, which solved the
outage but left the wrong user-visible destination.

## Current truth

Scott authorized a coherent soft-launch rebrand and the ordinary Vercel, Clerk,
and domain configuration needed for the normal address to work end to end. The
Family Core and Project Philosophy require one durable product identity, the
person / your AI / workspace split, honest Current / Partial / Later claims,
and preservation of Family History's archival compass, paper, teal/rust,
annotation, evidence-thread, typography, and editorial character.

Version 2.0.0 is Public & live. The code treats the
old product and Vercel hosts as compatibility redirects to
`assistwithfamilyhistory.com`; updates product/service naming, public and app
shells, Queue and AI language, metadata/social cards, extension presentation,
and current documentation. Clerk names Assist With Family History, uses the new
primary domain, and reports the required DNS configuration verified. Its new
issuer serves valid HTTPS discovery. Vercel and Convex now run the matching
production configuration, and isolated signed-in web plus OAuth/MCP acceptance
passed on the canonical address.

removed. A provider recheck returned zero active sessions before testing resumed.
