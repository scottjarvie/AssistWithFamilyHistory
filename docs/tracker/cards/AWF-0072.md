## Why this exists

A whole-tree import (AWF-0071) raises `possibly_same_as` suggestions and
brings in notes on people, facts and couples. Today a connected AI can read
them, but the person has no screen to see or decide them.

## Current truth

- Suggestions live in `connections` (relation `possibly_same_as`, state
  `proposed`, `importJobId` set). Notes live in `notes`, keyed by subject.
- `family_history_get_tree_import` already returns suggestions with a
  `/app/people/{id}` link.

## Next safe action

On `/app/people/[id]`: a "Might be the same person" panel (accept marks the
connection accepted; reject marks it rejected; neither merges), and a Notes
section. Optionally an Imports panel listing `treeImports` with progress.

## Constraints

No merge. Merging people is a separate decision for Scott.
